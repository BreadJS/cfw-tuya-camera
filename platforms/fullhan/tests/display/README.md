# Display configuration and clock tests

Run `python3 custom-firmware/tests/display/test_settings.py`. Ten host tests compile the real module with ASan/UBSan and use disposable private `/tmp` directories. No camera configuration, device or flash is accessed. Static ARMv6 EABI5 soft-float linkage was also checked; the executable was not deployed.

`camera_display_defaults` sets name `Camera`, timestamp disabled, timezone 0 (Europe/Amsterdam). `camera_display_valid` returns 1 for valid settings and 0 otherwise; load/save/format return 0 on success and -1 on failure. Names are nonempty strings of at most 63 bytes of strict UTF-8 scalar values, with ASCII controls and DEL rejected. Overlong encodings, surrogate values, truncated sequences and values above U+10FFFF are rejected.

The private `display.conf` record is exactly 80 bytes: `CAMDSP1\0`, little-endian uint32 timestamp-enabled and timezone, then a zero-padded 64-byte name. Load requires a regular one-link file owned by the service UID, mode exactly 0600, the exact record size/header and canonical zero padding. Missing files yield defaults; failed loads leave the supplied output unchanged. Directory FDs must name private directories owned by the service UID. Save creates a distinct `display.tmp.PID.SERIAL` using exclusive/no-follow creation, sets mode 0600, writes and fsyncs it, atomically renames it, then fsyncs the directory. A reported failure after rename may already have committed the change. Existing unsafe symlink/hardlink targets are rejected.

`camera_display_format_clock` produces exactly `YYYY-MM-DD Thu HH:MM:SS` (23 bytes plus NUL) without changing global timezone state. Timezone 1 uses UTC; timezone 0 applies CET/CEST using the last Sunday in March at 01:00 UTC through the last Sunday in October at 01:00 UTC. It uses `gmtime_r`/`timegm` and fixed English weekday names, independent of locale and process TZ. These specified modern European rules are projected onto the supplied year; this is not a historical timezone database.

Tests exercise absent defaults, actual save/reload and replacement, exact wire format/mode, UTF-8 boundaries, invalid flags, malformed record/size/padding, unsafe files/directories, 2026 DST boundary seconds, UTC, leap day and date/year rollover. The harness sets process TZ to Honolulu before formatting to check independence. Root integration owns reset-whitelist additions for `display.conf` and exact `display.tmp.PID.SERIAL` names.
